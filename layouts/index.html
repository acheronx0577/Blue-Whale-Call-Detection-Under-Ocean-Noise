Write the finished set

The technical files are written first. report.md is written after them.

decisions.csvEvery 25-second graph, with the sound it came from, bat, baf, Laya’s choice, and the reason.
decisions.jsonThe same rows, for a program to read.
call / not-call / reviewOne folder per pile. Each holds a manifest of the graphs Laya sorted there. Review will be an empty manifest.
report.mdThe counts in sentences, then the comparison: one call, the rest low, quieter and noisier pairs shown.
