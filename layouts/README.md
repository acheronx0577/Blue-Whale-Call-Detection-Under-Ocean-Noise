# Whale Mix screens

One full-width page, three steps. Open `index.html`.

The left sidebar only lists pages. The open page has the large title. Graphs, Sort and compare, and Export sit under that title. The selected row stays on the right.

1. Drop whale sounds in the sidebar. The middle table is the spectrogram made from each 25-second window.
2. Sort by call, not-call, and review. Switch the view. The chart compares bat with baf, and bat with the 63 Hz level.
3. Export the CSV, JSON, three folders, and report.md.
